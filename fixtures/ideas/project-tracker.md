I want a simple project tracker for myself. I sign up and create projects with a
name, a short description and an optional due date. Each project has tasks with a
title, a status (To do, In progress, Done), a priority (Low, Medium, High) and an
optional due date.

I want to see all my projects with how many tasks are still open, open a project
to see its tasks, filter tasks by status and priority, search tasks by title, and
mark a task done quickly. Overdue tasks should stand out. I can edit and delete
projects and tasks; deleting a project deletes its tasks.

Clean and calm, a bit like Linear but warmer.
