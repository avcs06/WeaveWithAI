# 62 · P4 Demo video and submit

Phase 10 · 2 h · Depends: P3 · Gate G9

## Goal

A 3-minute video that shows only what was built this week, uploaded, and
the form submitted before Wed Nov 4, 9:00 PM ET (Thu Nov 5, 7:30 AM IST).

## What this step does

1. **A timed 3-minute script** that shows only this week's work, with the
   benchmark table as the centrepiece and a defect being caught and
   repaired.
2. **Record, cut, upload** unlisted to YouTube; check the link signed out.
3. **Submit the form** from the drafted answers, screenshot the confirmation.

After this step gate G9 is met.

## Implementation details

### 1. Script (3:00, timed)

- 0:00 The idea file for the freelancer workspace, one sentence on Weave.
- 0:20 `pnpm weave run …`: the stage lines scrolling; cut to `01-flows/04-reconcile.md`.
- 0:45 `02-design/09-assemble.md` (or the wireframes) and the theme swatches.
- 1:05 `03-contract.md`, then the coverage matrix with a mismatch fixed.
- 1:25 The generated app in the browser: sign in, create a project, add
  a task; `web/mocks/db.json` gaining the row.
- 1:50 `05-benchmark.md`: the per-route table, the duplicates section,
  the screen-reader log for one route.
- 2:15 A failing e2e test, the repair request, the session fixing it,
  tests green, the benchmark delta.
- 2:40 The dashboard: numbers (runs, rounds, tokens, cost, lines by
  origin), the Modal run, and the line "the design system existed; the
  generator is this week's work".
- 2:55 Repository URL.

### 2. Record and upload

1080p, OBS or Loom, terminal font large, no audio gaps; one take per
segment is fine, cut together. Upload unlisted to YouTube; check the link
in a private window.

### 3. Submit

Fill the form from `docs/SUBMISSION.md`; paste the video URL; tick the
consent box; submit; screenshot the confirmation into `docs/SUBMISSION.md`.
Optional: an X post with the video for the Most Viral prize, its link in
the form.

## Done when

Gate **G9**: the video is public (unlisted), the form is submitted, the
README is final, and `docs/SUBMISSION.md` records the confirmation.
